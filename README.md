# Homebrew tap for Tilde

[Tilde](https://github.com/tevans2/tilde) is a keyboard-first file navigator for macOS.

```sh
brew install --cask tevans2/tilde/tilde
```

`brew upgrade` updates it. `brew uninstall --zap tilde` also removes its index, undo
history and preferences (your `~/.config/tilde` stays).

The cask is updated by Tilde's release workflow; don't edit it by hand.
